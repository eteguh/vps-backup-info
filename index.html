VPS Backup Automation

A personal-use utility for encrypted backups, recovery checks and backup retention using Google Drive.

This is an informational website. It does not provide a public backup service, sign-in form or access to backups.

What the utility does

The utility uses restic and rclone to encrypt selected owner-controlled data before uploading it to an owner-authorized Google Drive account. Authorized operations include creating and reading backup objects, checking repository and storage metadata, restoring selected recovery points and removing expired backup objects under reviewed retention settings.

Local working copies support consistent capture and isolated recovery validation. Production setup and activation are supervised; this page does not assert that production backup or recovery acceptance has completed.

Google account access

Google OAuth is used to authorize the utility. The intended Drive permission is drive.file, which permits access to files associated with the app or explicitly made available to it. The utility is configured for the owner's backup destination. A configured folder is not an independent OAuth security boundary.

The utility does not request Google account passwords. Authorization takes place through Google, separately from this website.
